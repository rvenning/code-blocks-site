Common questions

My code did not appear in the exported PDF or Word document

It should. This is the specific problem the app was built to solve, so please report it — include the page and the export format you used. As a check, confirm the macro shows your code on the page itself first; an empty macro exports as an empty block.

My language is not in the list

The dropdown offers a curated set of the most commonly used languages rather than all 200+ that the underlying highlighter supports. If yours is missing, email the name and it will be added. Meanwhile, choose Plain text — the code will render correctly, just without colouring.

Highlighting the wrong lines, or nothing highlighted

The highlight field takes line numbers and ranges only, for example 3, 1-5, or 1-5,9,12-14. Anything else is rejected when you save. Line numbers count blank lines. Highlighted lines are shaded and marked in the line-number column, so line numbers are always shown when a block has highlighted lines. Line highlighting is shown on the page; exports contain the code without the highlight bands.

Word export has no syntax colours

That is expected. Confluence’s Word export renders every code block, including its own built-in one, as plain fixed-width text. Your code, line breaks and indentation are preserved. For coloured code in a document, export to PDF.

Can I get my code back if I uninstall the app?

Yes. Your code is stored in the Confluence page itself, not in the app. Uninstalling does not remove it, and it remains in the page’s content and version history.

What data does the app collect?

None. The app requests no Confluence permissions and makes no external network calls. See the privacy policy.
