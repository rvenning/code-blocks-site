Code blocks that survive the export

Syntax-highlighted code for Confluence Cloud — and it is still there when you export the page to PDF or Word.

Find it on the Atlassian Marketplace

What it does

  • Syntax highlighting for 46 of the most widely used languages.
  • Line numbers, and highlighting for any line or range — for example 1-5,9. Highlighted lines are shaded and marked in the line-number column.
  • An optional title, so a block can be labelled with its filename.
  • Long lines either wrap or scroll, your choice per block.
  • Renders into PDF and Word exports, which is the reason it exists. PDF keeps the syntax colours. Word keeps the code, its line breaks and indentation in a fixed-width font, but not the colours: Confluence’s Word export does not colour any code block.

Nothing to configure

There is no global settings page, no administrator setup and no rules to write. Insert the macro, paste your code, pick a language. That is the whole product.

Your code stays yours

The app requests no permissions at all. It makes no API calls, stores nothing, and sends nothing anywhere — which is what qualifies it for Atlassian’s Runs on Atlassian standard.

Your code is saved in the Confluence page itself, not in the app. If you ever uninstall Code Blocks, the content is still in your page.
